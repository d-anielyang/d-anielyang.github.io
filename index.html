Field notes

Cat. 01 / About

We're Dodo — a design-and-build studio that plans, permits, and builds under one roof. No handoff between an architect and a separate contractor, no gaps where a project can fall through.

The dodo felt right as a namesake: written off as clumsy, actually resourceful. We like proving assumptions wrong, one renovation at a time — on budget, and built to outlast the trend it started in.

How a project runs

Cat. 02 / Services
01 — Design

Plan

We measure your space, listen to how you actually live in it, and draw a plan that fits both. Drawings, materials, and a real budget before anything is booked.

02 — Permit

Prepare

We handle permitting and scheduling so the paperwork doesn't stall the project. You get a clear timeline before the first wall comes down.

03 — Build

Build

Our own crews build it — the same team that designed it. Weekly updates, no surprise change orders, one walkthrough at the end where everything is already finished.
